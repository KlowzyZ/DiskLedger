# DiskLedger screenshots

Captured automatically on Windows by DiskLedger's `--smoke-test` mode for **v2.0.0-preview.1**, using the built-in
**demo mode** (invented drives in a separate demo ledger, at a 1024×768 runner resolution). They show the user interface,
not results from real hardware.

| File | Screen |
|---|---|
| `dashboard.png` | Dashboard — connected drives, "seen before" recognition, data sources |
| `drive-details.png` | Drive details — latest readings, changes since previous test, trends, timeline, SMART table |
| `drives.png` | Drives inventory |
| `history.png` | History search — "has this drive been tested before?" |
| `workshop.png` | Settings → Workshop connection |
| `dashboard-arabic.png` | Dashboard in Arabic (right-to-left) |
