DiskLedger 2 is a complete rebuild: **one Windows application** that recognises every drive you have tested before and shows what changed. No server, services, database, scripts, .NET runtime or Hard Disk Sentinel required.

Windows 10 (1809+) or Windows 11, 64-bit. The binaries are **not code-signed** yet — SmartScreen may warn; verify the checksum.

## What's new
- Single app replaces 0.1's Agent + Server + Desktop. Works on one PC immediately; optional encrypted workshop mode for several PCs (set up in the app with a setup code).
- Native Windows drive discovery: model, serial, capacity, interface, HDD/SSD/NVMe, Windows health. SMART and NVMe health data with *Restart with full access*.
- Hard Disk Sentinel Professional is optional; when present its health percentage is recorded and labelled as Sentinel's.
- Honest readings: missing values are shown as *Unavailable* with the reason; no invented health score.
- History per drive per day, change events, trend charts, timeline, notes, search by partial serial.
- 0.1 history is imported automatically (originals untouched). Daily backups, CSV/JSON export.
- English, Turkish and Arabic (RTL). Official KLOWZY DiskLedger icon.

## Known limitations
- Not yet verified on physical HDDs, SSDs, NVMe drives and USB adapters.
- SMART through USB depends on the adapter; unsupported adapters show *Unavailable*.
- SAS drive health (SCSI log pages) not read yet.
- Monitoring runs while the app runs (tray, optional start at sign-in); there is no Windows service.
- Turkish and Arabic translations await native-speaker review.
